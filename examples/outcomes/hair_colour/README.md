## Data Note

This study was conducted on externally collected data covering Indian consumer conversations about hair colour products. Data spans multiple years across five platforms. No engagement thresholds applied - every consumer voice entered the corpus equally. Relevance filtering removed non-Indian language content and off-topic items. In-context analysis by Claude Code session (zero API cost).
